# Vino Veritas : portail Calloway & Sons

Outil JDR (Vampire la Mascarade V5) : portail du négociant Calloway & Sons et cercle de dégustation de la joueuse Ventrue.

- `index.html` : portail (connexion, lettre, contrat de garantie, fondation du cercle, compte). Vue MJ si le compte a le rôle `mj`.
- `carte.html` : carte de visite recto/verso avec QR code vers le portail.
- Données : Supabase (projet de l'organisation Vino-Veritas). Fichiers statiques, aucun build : déploiement Vercel direct.
